# protowx user manual

How to keep calculations on the page, and evaluate them. This manual
is for people who use the page, not for people changing the engine; the
design notes live in [`docs/features/`](../../features/).

The pages are of four kinds. A **tutorial** is a lesson. A **guide** is
a task. A **reference** describes one thing exactly. An **explanation**
says why.

| page                         | kind       | what it covers                                         |
|------------------------------|------------|--------------------------------------------------------|
| [changelog.md](changelog.md) | change log | what changed in how you work on the page, newest first |

The names of the parts on screen are in the [glossary](../../glossary.md).
